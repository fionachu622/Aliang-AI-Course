# 教学视觉设计说明

## 核心理解目标

观众看完后应能复述：大模型不是一次写完答案，而是把文字编码成 Token / Token ID，再不断预测下一个 Token，最后解码为回答。最难理解的是“产品与模型的关系”“Token 不是字词字符”“生成是反馈循环”三处。

## 整体视觉结构

全课使用同一条横向视觉地图：输入文字 → Tokenizer → Token / ID → 大模型 → 回答。讲解局部时只放大当前节点，其他节点保留或弱化，避免每段重新寻找位置。

## 分镜与口播节拍

| 段落 | 视觉焦点 | 主要变化 | 锚点 |
|---|---|---|---|
| 01 产品与模型 | 产品卡片 → 大模型 | 先出现产品，再在口播说到“大模型”后揭示核心能力 | 产品在左、模型在右 |
| 02 LLM | 缩写与工作定义 | 名称、定义、暂不展开项依次出现 | 左名称、右定义 |
| 03 预测下一个 | 概率条与反馈循环 | 候选项随口播出现，随后才显示概率与循环 | 句子始终在顶部 |
| 04 流式生成 | Token 连续长出 | Token 一个接一个出现，再解释不是假打字 | 流程地图保持不变 |
| 05 Token 定义 | 定义与三个“不等于” | 先给定义，再逐个拆误解 | Token 固定居中 |
| 06 Tokenizer | 文字 → 切分 → Token | 聚焦流程中的 Tokenizer 节点 | 横向流程地图 |
| 07 编解码 | 文字与数字表示互换 | 编码向右、解码返回可读文字 | 同一条流水线 |
| 08 切分不固定 | 四类文本对比 | 中文、英文、数字、emoji 逐个出现 | 四格位置固定 |
| 09 实际演示 | 两组输入样本 | 先中文、后混合文本，实测输出留替换位 | 左右对照 |
| 10 三个影响 | 容量、长度、成本 | 三张卡按口播逐张出现，最后回到全流程 | 三列固定 + 流程复现 |

## 注意力约束

- 同一时刻只出现一个主要信息增量。
- `RevealAt` 时间点均设置在对应口播短语之后，并保留约 0.3–1.5 秒安全余量。
- 不使用 CSS animation / transition；动画全部由 Remotion 帧驱动。
- 不把旁白整段抄到屏幕，只显示结构、关系、关键词和结论。
- 第 9 段不伪造 Tokenizer 结果；未选模型前保留明确替换位。
