# AgentTeachingV5 视觉约束

- 课件文字（包括英文 Agent）保持既定粉笔手写字体；字幕按用户要求使用清晰的无衬线黑体（PingFang SC 优先），不得套用粉笔字体。框线、箭头保持粉笔手绘。未经用户明确要求不得换成无衬线字体或规整 UI 风格。
- 口播揭示时间保持不变；本版按用户授权重新选择内容组织形式，决定记录在 page-forms.storyboard.json。
- 用户要求：插画与标签必须有明确间隙，不能贴边或相碰。以 1920×1080 原画幅为基准，插画可见下边缘到标签实际字形上边缘至少 32px；并列组保持接近的视觉间距。
- 相邻文字也须按实际字形边界留出至少 24px；包括同一线框内的英文标题、中文注释和动作文字。动画过渡中如有两个文本块水平靠近，先检查它们的可见字形是否碰撞，再调整移动顺序。
- 不能把 SVG text 的 y 当作文字顶边；y 是基线。透明 PNG 需要计入实际 alpha 边界、preserveAspectRatio 缩放与留白。
- 每次修改图片尺寸、坐标、字体或字号后，交付前必须检查图文间距、对齐、裁切、相邻元素碰撞。复核实际合成的稳定帧与过渡关键帧，并在缩小后的播放尺寸下查看。
- 类型检查、时间点检查通过不等于排版通过；不能仅凭这两项宣称视觉已检查。
- 用户明确要求交付前自行判断视觉效果。卡面与插画先在独立候选预览中检查手绘质感、主次、噪声和缩小可读性；有明显问题的候选继续修改，不直接更新到用户正在看的版本。自审通过后再核对真实合成，不能把“已经渲染”当作审美通过。
