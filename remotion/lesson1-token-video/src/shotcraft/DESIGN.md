# Lesson1ChalkboardShotcraft · 动效试验

模式：用户已确认自主创作；范围仅动效。基线是 Lesson1ChalkboardV3，放在 skill测试 中对照，不替换第1课里的终版。

## 制作基准与约束

- 受众是第一次学习大模型、Token 的课程学员，目的不是推销产品。
- 复用原有 React/SVG、黑板图片、HanziPen SC 字体、字号、布局、粉笔色板。已有明确终版视觉，跳过另做 styleframe；基线截图在 out/qa/shotcraft/baseline-*.png。
- 12 个场景、顺序、文字、示例、真实 Tokenizer 截图、录音均不变。
- 时间唯一来源为 PACING_V2_SCENE_TIMING_OVERRIDES / PACING_V2_SCENE_BOUNDARIES；525.24 秒音频、15758 帧 @30fps；不按动效重新分配口播时间。
- 不加说明文字、框、按钮、人物、概率星图；不加音乐、音效、全屏闪烁、抖动或 3D 旋转。
- 输出仍为可编辑 Remotion 网页，不导出视频，不改录音，也不另起宣传片工作台。
- 素材仅复用本课程现有内容，不采集用户数据。真实页面截图不重画，抽象教学对象继续使用矢量组件。

## 方向与取舍

选择「安静、清晰、连续」；放弃宣传片高能开场/发布会峰值收尾。背景固定，图文在同一平面运动。文字与关系落定后保持静止，不用循环微动制造存在感。

| 需求 | 执行 |
| --- | --- |
| 保留老版 | 只为新 composition 提供动效上下文；共享组件默认 null 分支严格保留旧样式，静帧回归对照 |
| 逐步出现 | 既有 cue 不变；同一语义对象整体入场，透明度/位移/清晰度同步结束；独立的淡出/弱化通过 motionVisibility 相乘，不覆盖入场透明度 |
| 聚焦疑问 | 原有上下文退场时机不提前；用途从两侧向中间以 4f 错峰、14f 加速退出；原有问号进入，一句话→回答整体轻微靠近屏心并停住 |
| 关系可读 | 既有箭头/下划线复用原路径；同路径短 dash 笔头在描画期出现、落定后移除 |
| 跨页不抢戏 | 使用 24f 接缝预算；固定黑板、16f 失焦/收焦，2f 错峰；前页尾帧延续到边界后交接，下一页 cue 时钟严格从原起点启动，不预播未来内容 |
| 连续动作不被打断 | generation-loop、streaming 保留原无缝衔接；Tokenizer 的 apple 弹簧归位、既有 Token 流动和形态转换保留 |

## 卡片映射（已核对 Gallery 索引并完整读取对应 demo）

1. `blur-slide` / `blur-slide` → `demos/typography/blur-slide/BlurSlide.tsx`。
   复用三通道共用 outCubic 的语法；保持词组为单位。沿用现有 cue 窗口而非给中文逐字错峰。幅度按课堂画面缩为原 Layer 的短距离，blur 上限 10px；保留前后原坐标/字号，移除多余缩放弹入。将现有进度直接输入 outCubic，让拉长到数秒的口播窗口尽早清晰，起止锚点不变。
2. `draw-svg-trace` / `draw-svg-trace` → `demos/ui-entrance/draw-svg-trace/DrawSvgTrace.tsx`。
   采用下划线短版，不采用闭合框/闪黑；7px 笔头，dash 长 .09，同路径跟随，.03–.97 可见，结束常驻原线。扩展到现有关系箭头，不增加任何新关系。
3. `shot-transitions` / `shot-transitions-5` → `demos/transition/shot-transitions/FocusHandoffTransition.tsx`。
   复用 16f / 2f 错峰 / 8px 最大模糊 / 两条原 demo bezier / 60px、50px 小幅位移，使用 24f 接缝。教学场景首帧常为空，因此不提前冻结空首帧；改为延续前景最后一帧、在下一页原始 cue 时钟启动后交接。不预播未来内容。黑板纹理保持不动。
4. `ui-strip-away-outro` 为分析参考，不作为完整卡片复刻：终结性 Publish 语义不适用教学提问。因此不使用按钮/光晕/品牌字标；自定义「疑问聚焦」只借鉴外围先退出的组织方式，明确不是同款 outro。
